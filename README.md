# 🚀 Project 7: Modular & Packager — Multi-Utility Toolkit

## 📌 Project Overview

The **Multi-Utility Toolkit** is a menu-driven Python project that combines multiple useful operations in one program. It demonstrates the practical use of Python's built-in modules, functions, loops, conditional statements, exception handling, and file handling.

Users can select different options from the main menu to perform mathematical calculations, date and time operations, random data generation, UUID generation, file operations, and module exploration.

## ✨ Features

### 1. 📅 Date and Time Operations

* Display the current date and time.
* Calculate the difference between two dates.
* Format dates and times.
* Use a stopwatch to measure elapsed time.
* Run a countdown timer.

### 2. 🧮 Mathematical Operations

* Calculate the factorial of a number.
* Calculate compound interest.
* Perform trigonometric calculations:

  * Sine
  * Cosine
  * Tangent
* Calculate the area of different geometric shapes:

  * Circle
  * Rectangle
  * Triangle
  * Square

### 3. 🎲 Random Data Generation

* Generate a random number within a specified range.
* Generate a list of random numbers.
* Create a random password.
* Generate a six-digit OTP for demonstration purposes.

### 4. 🆔 Unique Identifier Generation

* Generate UUID1 identifiers.
* Generate UUID4 identifiers.

### 5. 📂 File Operations

* Create a new file.
* Write content to a file.
* Read file contents.
* Append content to an existing file.
* Handle common file errors.

### 6. 🔍 Explore Python Modules

* Explore the `math` module.
* Explore the `random` module.
* Explore the `datetime` module.
* Explore the `os` module.
* Display available module attributes using `dir()`.

## 🛠️ Technologies Used

* **Programming Language:** Python 3
* **Modules:** `datetime`, `time`, `math`, `random`, `uuid`, `os`, `secrets`, `string`
* **Concepts:** Functions, loops, conditional statements, exception handling, file handling, and modular programming.

## ⚙️ Installation and Setup

### Prerequisites

* Python 3 installed on your system.
* A code editor such as Visual Studio Code.

### Steps to Run

**1. Clone the repository**

```bash
git clone <your-repository-url>
```

**2. Navigate to the project folder**

```bash
cd Project-7-Modular-Packager
```

**3. Run the Python program**

```bash
python project7.py
```

If your system uses the `py` command on Windows, run:

```bash
py project7.py
```

No external Python packages are required because the project uses Python's standard library.

## 🖥️ How to Use

1. Run the Python file.
2. Select an option from the main menu.
3. Follow the instructions displayed in the terminal.
4. Enter the required values.
